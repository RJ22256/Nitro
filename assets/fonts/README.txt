Optional: SST font for Nitro's interface
========================================

Nitro's app and in-game menu use Sony's SST typeface (the PlayStation UI
font) when they can find it, and Segoe UI otherwise.

SST is a commercial font, so it isn't included with Nitro. If you have a
licensed copy, put these files in this Fonts folder (next to Nitro.exe):

    SSTRg.TTF       regular text
    SSTMedium.TTF   labels and buttons
    SSTBold.TTF     the NITRO title

Installing SST in Windows works too. Restart Nitro (and the game) afterwards.
